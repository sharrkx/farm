Privacy policy

Last updated: October 24, 2026

"Mindrift Analytics" is a private tool used only by the owner of the Mindrift channel.

Data we access

With the owner's authorization, the app uses the YouTube Data API and YouTube Analytics API with read-only scopes (youtube.readonly, yt-analytics.readonly) to read statistics of the owner's own channel: video titles, views, watch time, likes, comments and shares counts.

How we use it

The statistics are stored on the owner's private server and used only to analyse which videos perform well. Data is not sold, shared with third parties, used for advertising, or used to train AI models.

Storage and deletion

The access token is stored on the owner's server with restricted file permissions. Access can be revoked at any time at myaccount.google.com/permissions; the stored statistics are deleted on request.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service and the Google Privacy Policy.

Contact

The channel owner: via the support email shown on the app's Google consent screen.
